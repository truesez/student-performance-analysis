# student-performance-analysis

> A simple Python project that analyzes student marks and visualizes academic performance using charts.

## Problem & Users

Students and teachers may find it difficult to understand academic performance by looking at marks alone.

This project helps students, teachers, and educators summarize marks and identify performance patterns.

## Features / Solution

- Calculate average student marks.
- Display student scores in a table.
- Create charts to visualize academic performance.
- Identify the highest and lowest scores.

## Architecture

The project follows a simple workflow:

1. Load student marks.
2. Process the data using Pandas.
3. Analyze the results.
4. Display charts using Matplotlib.

## Prerequisites

- Python 3.9 or later
- Basic knowledge of Python
- Pandas
- Matplotlib

## Installation

Clone the repository:

```bash
git clone https://github.com/truesez/student-performance-analysis.git
cd student-performance-analysis
```

Install the required libraries:

```bash
pip install pandas matplotlib
```

## Quick Start / Usage

1. Open the Python script.
2. Enter or load the student marks.
3. Run the script:

```bash
python main.py
```

4. View the calculated results and performance chart.

## Example Output

Sample student marks:

| Student | Marks |
|---|---:|
| Student A | 85 |
| Student B | 72 |
| Student C | 90 |
| Student D | 65 |

Average marks: 78

Highest marks: 90

Lowest marks: 65

The project can also display a bar chart comparing student marks.

## Data / Model

This project uses a small sample dataset containing student names and marks.

No AI model or machine learning algorithm is required.

## Limitations

- Uses a small sample dataset.
- Does not predict future academic performance.
- Results depend on the accuracy of the input data.
